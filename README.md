# Financeiro Driver

Site estático para controlar custos, meta e ganhos de um motorista de app.

## Estrutura

- `index.html` — página principal
- `logo-onix.svg` — logo da marca (opcional)

## Como rodar localmente

Open a pasta no navegador ou rode um servidor local:

```bash
cd "c:\Users\rodsi\OneDrive\Área de Trabalho\ProjetoWebUber\financeiroUber"
python -m http.server 8000
```

Depois abra:

```text
http://localhost:8000/
```

## Deploy gratuito

Recomendado: GitHub Pages.

1. Crie um repositório no GitHub.
2. Envie esses arquivos.
3. Vá em Settings > Pages.
4. Escolha a branch `main` e a pasta raiz.
5. Salve.

Seu site ficará em um link parecido com:

```text
https://SEU_USUARIO.github.io/NOME_DO_REPO/
```
